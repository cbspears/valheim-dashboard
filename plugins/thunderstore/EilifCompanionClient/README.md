# Eilif Companion Client

Custom plugin for the **Eilif** community Valheim server ([dashboard](https://valheim-dashboard.vercel.app)).

While you play on the server, your explored-map percentage flows to the dashboard's **Cartographer** leaderboard automatically — no setup, no uploads, nothing to press. Reads your own map locally and posts a single number on an interval and at logout.

Endpoint and token are pre-configured by the Eilif modpack (`net.eilif.companionclient.cfg`). Does nothing on other servers unless configured.
